# Política de cancelación (referencia)

- Con 24 h o más de anticipación no hay cargo; entre 2 y 24 h se cobra el 50 %; con menos de 2 h no se puede cancelar.
- Tres ausencias sin aviso piden una seña para reservar de nuevo.
- Es una referencia para el módulo `extras/cancellation-policy` y `extras/noshow-tracker`; la API actual solo marca el turno como cancelado.
